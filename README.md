# VAT_Baker Landing Page

Landing page para VAT_Baker optimizada para GitHub Pages.

## Estructura

```
WEB/
├── index.html          # Landing page principal
├── package.json       # Configuración npm
├── .gitignore         # Archivos ignorados
└── assets/           # Tus imágenes (agregar aquí)
    ├── promo.png     # Imagen principal
    ├── hero.png      # Imagen del hero
    └── screenshot.png
```

## Imágenes

Para que la landing page muestre tus imágenes:

1. Crea una carpeta `assets` dentro de `WEB`
2. Agrega tus imágenes:
   - `promo.png` - Imagen de la sección About
   - `hero.png` - Imagen del hero (opcional)

Después actualiza el HTML para usar tus imágenes cambiando:

```html
<!-- En la sección About -->
<img src="assets/promo.png" alt="VAT_Baker Demo">

<!-- En el Hero (opcional) -->
<img src="assets/hero.png" alt="VAT_Baker">
```

## Publicar en GitHub Pages

1. Sube el contenido de `WEB/` a un repositorio GitHub
2. Ve a **Settings > Pages**
3. En "Branch" selecciona `main` y carpeta `/ (root)`
4. Guarda los cambios
5. La página estarán disponible en: `https://tu-usuario.github.io/repo/`
